# Binary Tree Reconstructor
This program reconstructs a binary tree given an in-order sequence and a post-order sequence.

## How to run:
### CLI:
1) Ensure you have .Net10
2) Navigate to the folder with the `.csproj` file (./BinaryTreeReconstructor)
3) Run the program with `dotnet run`
### Visual Studio:
1) Open the `.slnx` file in Visual Studio
2) Locate and click the play button or click Debug in the menu and select "Start Debugging" or "Start Without Debugging" from the dropdown
